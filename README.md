Software Name: Google Collab (Python Version 3.9.0)

Step 1: Open Google Collab software

Step 2: Click Upload and select the file named
MENTAL_HEALTH_PREDICTION.ipynb
After selecting the file, click on Open, then click on the Upload button to complete the upload.

Step 3: Place the dataset file
Mental-Health-Twitter.csv
in the same location as the .ipynb file.
(Upload it the same way as mentioned in Step 2.)

Step 4: There are two ways to run the notebook file:

Click on the Kernel menu, then click on Run (To execute one cell at a time manually)

Click on the Kernel menu, then click Restart & Run All (To run all cells from start to finish in one click)

Step 5:
All outputs, visualizations, and evaluation results will be displayed inside the
MENTAL_HEALTH_PREDICTION.ipynb
after successful execution.
